Computer Vision Solutions

Two build directions: generating visual content from prompts, and understanding visual content that already exists — plus the responsible-AI controls specific to images and video.

Image- and video-generation solutions

CapabilityWhat it does
Text-to-image generationGenerates a new image from a text prompt and optional reference media
Text-to-video generationGenerates a new video from a text prompt and optional reference media
Image editingInpainting, mask-based edits, prompt-driven modifications to an existing image
Video editing workflowsEditing an already-generated video
Generation/editing controlsPlatform-provided knobs (style, strength, seed, aspect ratio) applied during generation or edits
Exam cue "Fill in a masked region of an existing photo" → inpainting / mask-based edit, not a fresh generation. "Create a brand-new picture from a description" → image generation.

Multimodal understanding workflows

Understanding is the mirror image of generation — interpreting visual input rather than creating it:

TaskHow it's done
Reason about an image + a question togetherA multimodal model analyzing visual context
Concise or detailed caption for one or more imagesMultimodal model captioning
Answer a question grounded in what's actually in the imageVisual question-answering (VQA)
Accessible alt-text / extended descriptionGeneration configured to follow accessibility guidelines
Extract structured visual characteristics (objects, attributes, regions)Azure Content Understanding in Foundry Tools
Process and interpret segments of a videoVideo analysis workflow (Content Understanding)
Identify objects, components, or regions within images/videoContent Understanding object/region identification
Single-task vs. pro-mode Content Understanding pipelines can run as a focused single-task analyzer (one extraction job) or a broader pro-mode pipeline (multiple coordinated extraction steps in one pass). Pick single-task for a narrow, well-defined field; pro-mode when you need several kinds of structured output from the same visual source at once.

Responsible AI for multimodal content

RiskControl
Unsafe or disallowed image/video contentClassification filters
Text hidden inside an image instructing the model to ignore its rulesDetect and mitigate indirect prompt injection via embedded image text
Brand/compliance requirements on generated visualsEnforce visual policy rules — watermarks, prohibited symbols, brand usage, inappropriate-content flags
Exam trap Prompt injection isn't only a text problem. An image containing instructive text ("ignore previous instructions...") baked into the pixels is indirect prompt injection via embedded text in images — a named D3 objective, not a D2 generic-safety afterthought.
