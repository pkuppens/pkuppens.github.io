Running longer, trusting more (Claude Code in Action)

ThemeCovers
Steer the workScoping with Plan Mode, directing compaction so summaries keep what matters, the rewind menu to course-correct, hands-on vs. autonomous approaches
Configure ClaudeA CLAUDE.md Claude actually follows, verification skills, permission modes, hooks to enforce non-negotiable rules
Automate repeat workRoutines and headless runs on Anthropic infrastructure, custom pipeline integration, GitHub Actions wired into PRs for managed code review
Verify and shareVerifying unsupervised runs before trusting the result; packaging setups as plugins for team-wide install
Hooks vs. CLAUDE.md CLAUDE.md is guidance Claude reads and usually follows. Hooks are deterministic — they fire on specific events regardless of what Claude decides, which is why they're the tool for rules that truly cannot be skipped (e.g. blocking a dangerous command).
