The agent loop The recurring shape across this whole course: Claude acts (calls a tool or responds), observes the result, and decides what to do next — repeating until the task is done. Everything else (tool use, extended thinking, MCP) plugs into one of those three steps.

RAG vs. long context RAG (chunk, embed, retrieve) exists because working memory (Lesson 02) is finite and costly to fill — retrieval brings in only the relevant slice instead of stuffing everything into context.
Agent vs. workflow A workflow (chaining, routing, parallelization) is a fixed, predefined sequence of steps. An agent decides its own next step via the agent loop. Pick a workflow when the steps are known in advance; reach for an agent when the path itself needs to be figured out.
