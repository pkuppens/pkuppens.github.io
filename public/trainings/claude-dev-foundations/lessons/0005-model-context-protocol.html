Model Context Protocol (MCP)

The standard way to connect Claude to external tools and data — already referenced in Lessons 03 and 04. Here it's the whole subject: the three primitives, how servers and clients talk, and the production-grade transport details.

The three primitives (Introduction to Model Context Protocol)

PrimitiveControlled byWhat it is
ToolsThe modelOperations the model decides to invoke — executable functions
ResourcesThe appRead-only data, exposed via static or templated URIs
PromptsThe userPre-crafted instructions/workflows a user selects
Who's in the driver's seat The three primitives are distinguished by who decides to use them — the model (tools), the application (resources), or the person at the keyboard (prompts). Same protocol, three different control points.

The intro course builds this hands-on: set up a project, define tools with the MCP Python SDK (via decorators), inspect a server with the browser-based server inspector, then implement a client that accesses resources (with MIME-type handling) and surfaces prompts.

Going deeper (Model Context Protocol: Advanced Topics)

TopicCovers
SamplingHow an MCP server can request a language-model call through the connected client — inverting the usual direction
NotificationsProgress and logging notifications for real-time feedback on long-running operations
RootsA permission system granting a server access to specific directories, with defined security boundaries
JSON message typesThe full MCP message spec: request/result pairs and notifications
TransportsSTDIO (local, handshake over standard input/output) vs. StreamableHTTP (Server-Sent Events for server→client streaming, with session management)
Production considerationsStateless HTTP for horizontal scaling vs. stateful sessions — choosing a transport for deployment
Sampling is the odd one out Every other MCP flow has the client asking the server for something. Sampling flips it: the server asks the client to run a model call on its behalf — worth remembering precisely because it's the exception to the pattern.
