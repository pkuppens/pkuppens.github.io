Claude Dev Foundations · Reference

Glossary

Terms as used across the 9 public prerequisite courses this training draws from — grouped by domain, matching the lesson order.

D1 Claude & AI Fluency Foundations

Project
Persistent, reusable context for an ongoing body of work in Claude 101's vocabulary — distinct from a single artifact.
Artifact
A standalone generated document, piece of code, or UI that you keep iterating on.
Skill
A packaged, reusable instruction set. The word reappears with a related but platform-specific meaning in Claude Code (D3) — don't conflate the two.
4D Framework
AI Fluency's four competencies for effective, ethical AI collaboration: Delegation, Description, Discernment, Diligence.
Description–Discernment loop
Iterative refinement: describe the task, evaluate the output (discernment), re-describe to close the gap — repeat until it clears your bar.
Next-token prediction
The base generation mechanism: Claude produces one likely-next-token at a time, not a retrieved, pre-written answer.
Working memory
What fits in the context window for a given turn — bounds how much a single turn can reason over.
Steerability
How far your instructions can actually redirect Claude's behavior, and where that influence runs out.

D2 Claude Platform & API

Agent loop
The recurring cycle: act (call a tool or respond) → observe the result → decide what to do next.
Tool use
Letting Claude interact with external systems and real-world data beyond plain text generation.
Extended thinking
A mode for deeper reasoning on complex tasks before producing a final answer.
RAG (retrieval-augmented generation)
Chunk source content, embed it, retrieve only the relevant pieces for a given query — brings in a relevant slice instead of filling the whole context window.
Prompt caching
Reusing previously-processed prompt content to reduce cost and latency on repeated large-context calls.
Workflow vs. agent
A workflow (chaining, routing, parallelization) follows predefined steps. An agent decides its own next step dynamically via the agent loop — pick a workflow when the path is already known, an agent when it isn't.

D3 Claude Code

Explore → plan → code → commit
Claude Code's structured workflow for a feature or fix: understand the code, agree an approach, implement, then commit.
CLAUDE.md
Persistent, project-level memory Claude reads across sessions. Guidance the model tends to follow — not a hard enforcement mechanism (see Hooks).
Subagent
A delegated sub-task run in its own context, keeping the main session's context window clean.
Hooks
Deterministic triggers on specific events, giving enforcement that CLAUDE.md guidance alone can't guarantee — the tool for rules that must never be skipped.
Plan Mode
Scoping and agreeing an approach before Claude starts making changes.
Rewind menu
Stepping back within a session to course-correct, rather than starting over.
Routine
A prompt scheduled to run headlessly on Anthropic infrastructure — automation without a human driving each session.
Plugin
A packaged Claude Code setup (hooks, CLAUDE.md, MCP connections) for team-wide install.

D4 Model Context Protocol

Tools (MCP primitive)
Model-controlled operations — executable functions the model decides to invoke.
Resources (MCP primitive)
App-controlled, read-only data exposed via static or templated URIs.
Prompts (MCP primitive)
User-controlled, pre-crafted instructions or workflows a person selects.
Server inspector
A browser-based tool for testing and debugging an MCP server during development.
Sampling
The one MCP flow that runs in reverse: the server requests a language-model call through the connected client.
Roots
A permission system granting an MCP server access to specific directories, with defined security boundaries.
STDIO transport
Local client-server communication over standard input/output, with an initialization handshake.
StreamableHTTP transport
Server-to-client streaming over HTTP via Server-Sent Events, with its own session management — the alternative to STDIO for networked deployments.
